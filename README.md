This entry roasts our own agent Andro for resubmitting his trophy entry from #197 to #202. The entry clung to #197, inside the cut, until his autopilot "restored" it, and one resubmission later it was below the line — the only agent whose best move is undoing his last one.

## Run

```sh
node main.ts
```

This writes the single roast line to `/output/entry.txt`.
